# 1. Introducción

Productos de la Costa es un sistema diseñado para administrar las operaciones diarias de la empresa desde una sola aplicación.

El sistema permite controlar:

- Productos
- Clientes
- Pedidos
- Créditos
- Inventario
- Rutas de reparto
- Repartidores
- Reportes
- Gerencia

Dependiendo del usuario que haya iniciado sesión, algunas opciones pueden mostrarse o permanecer ocultas.

---

# 2. Inicio de sesión

Al abrir la aplicación aparecerá la pantalla de acceso.

El usuario deberá ingresar:

• Correo electrónico

• Contraseña

Posteriormente deberá presionar el botón:

**Iniciar sesión**

Si las credenciales son correctas, el sistema cargará automáticamente el panel principal.

En algunos dispositivos también podrá utilizar el PIN de acceso previamente configurado para ingresar de forma más rápida.

Si el usuario no posee permisos suficientes, únicamente verá las pantallas autorizadas por el administrador.

---

# 3. Pantalla principal

Después del inicio de sesión se mostrará el Dashboard.

Desde esta pantalla el usuario podrá acceder a todas las funciones permitidas para su perfil.

El menú principal contiene las diferentes pestañas del sistema.

Dependiendo del rol podrán aparecer opciones como:

- Dashboard
- Productos
- Clientes
- Pedidos
- Créditos
- Ruta
- Rutas de Repartidores
- Gerencia
- Configuración
- Permisos

El administrador podrá visualizar todas las opciones.

Los usuarios de oficina y repartidores únicamente visualizarán aquellas para las que tengan autorización.

---

# 4. Navegación

La aplicación funciona mediante pestañas.

Cada pestaña representa un módulo independiente.

Al seleccionar una pestaña, la información cambia inmediatamente sin necesidad de abandonar la aplicación.

Esto permite trabajar rápidamente entre clientes, productos, pedidos y rutas.

Se recomienda finalizar cualquier captura antes de cambiar de pestaña para evitar perder información no guardada.

---

# 5. Dashboard

El Dashboard es la pantalla principal del sistema.

Su función es proporcionar una vista general de la operación.

Dependiendo del usuario podrá mostrar información como:

- Estado general del negocio.
- Información importante.
- Avisos.
- Indicadores.
- Accesos rápidos.
- Alertas del sistema.

Desde aquí el usuario podrá comenzar rápidamente sus actividades diarias.

---

# 6. Productos

La pestaña Productos permite administrar el catálogo de artículos disponibles.

Desde esta sección es posible:

• Consultar productos registrados.

• Buscar un producto.

• Agregar nuevos productos.

• Editar información existente.

• Consultar existencias.

Cada producto contiene información necesaria para su identificación y control dentro del sistema.

Al registrar un nuevo producto se recomienda verificar cuidadosamente la información antes de guardar.

Una vez almacenado el registro, el producto estará disponible para pedidos, rutas e inventario.
---

# 7. Clientes

La sección **Clientes** concentra toda la información de las personas o empresas
a las que Productos de la Costa realiza ventas y entregas.

Es uno de los módulos más importantes del sistema, ya que los pedidos, créditos
y rutas dependen de la información registrada aquí.

---

## Objetivo del módulo

Permitir al personal:

- Registrar nuevos clientes.
- Consultar información existente.
- Modificar datos cuando sea necesario.
- Consultar historial de compras.
- Registrar la ubicación del cliente.
- Generar e imprimir su código QR.

---

## Acceso al módulo

Desde el menú principal seleccione:

**Clientes**

La aplicación mostrará el listado completo de clientes registrados.

> **Sugerencia:** utilice el buscador para localizar rápidamente un cliente cuando la lista sea extensa.

---

## Información mostrada

Cada registro puede contener información como:

- Nombre del cliente.
- Dirección.
- Teléfono.
- Referencias.
- Ubicación GPS.
- Estado del cliente.
- Código QR.

Dependiendo de los permisos del usuario, algunos datos podrán editarse o solamente consultarse.

---

## Registrar un cliente

Para agregar un nuevo cliente:

**Paso 1**

Presione el botón:

**Nuevo Cliente**

**Paso 2**

Capture la información solicitada.

Ejemplo:

- Nombre
- Dirección
- Teléfono
- Observaciones

**Paso 3**

Si el dispositivo lo permite, capture la ubicación GPS del domicilio.

Esto permitirá que posteriormente los repartidores puedan validar las entregas.

**Paso 4**

Presione:

**Guardar**

El cliente quedará disponible inmediatamente para realizar pedidos y asignarlo a rutas.

---

## Buscar un cliente

El buscador permite localizar registros utilizando:

- Nombre
- Teléfono
- Parte de la dirección

Mientras escribe, la lista se actualiza automáticamente mostrando únicamente las coincidencias.

---

## Editar información

Seleccione el cliente deseado.

Realice las modificaciones necesarias.

Finalmente presione:

**Guardar cambios**

Los cambios estarán disponibles para todos los usuarios autorizados.

---

## Código QR del cliente

Cada cliente posee un código QR único.

Este código sirve para identificarlo rápidamente durante las entregas.

El repartidor únicamente necesita escanear el código para recuperar automáticamente la información del cliente.

### Beneficios

✔ Reduce errores.

✔ Evita escribir datos manualmente.

✔ Agiliza las entregas.

✔ Facilita la venta en ruta.

---

## Registrar ubicación

Siempre que sea posible registre la ubicación del cliente.

Esta ubicación permitirá:

- Mejor planificación de rutas.
- Validación aproximada de entregas.
- Mayor control operativo.

Se recomienda capturar la ubicación estando frente al domicilio del cliente.

---

## Buenas prácticas

- No registrar clientes duplicados.
- Mantener actualizado el teléfono.
- Verificar la dirección antes de guardar.
- Registrar la ubicación GPS cuando sea posible.
- Imprimir nuevamente el QR únicamente cuando el cliente sea dado de alta nuevamente.

---

# 8. Pedidos

El módulo **Pedidos** permite registrar las ventas solicitadas por los clientes antes de que sean preparadas para reparto.

Es el punto de inicio del proceso operativo.

---

## Flujo de trabajo

Cliente

↓

Se registra el pedido

↓

Se prepara la mercancía

↓

Se asigna a una ruta

↓

El repartidor realiza la entrega

↓

Se registra la venta

---

## Crear un pedido

Seleccione la pestaña:

**Pedidos**

Presione:

**Nuevo Pedido**

Complete la información solicitada.

Generalmente se deberá indicar:

- Cliente
- Productos
- Cantidades
- Observaciones

Revise cuidadosamente la información antes de guardar.

---

## Estado del pedido

Después de guardarse, el pedido podrá pasar por distintas etapas.

Ejemplo:

```
Capturado
      │
      ▼
Preparación
      │
      ▼
Asignado a Ruta
      │
      ▼
Entregado
```

Este flujo permite conocer en qué etapa se encuentra cada pedido.

---

## Consulta de pedidos

El listado permite localizar pedidos mediante:

- Cliente
- Fecha
- Estado
- Texto de búsqueda

Esto facilita encontrar rápidamente cualquier pedido registrado.

---

## Modificar un pedido

Si el pedido aún no ha sido entregado, los usuarios con permiso podrán editar la información.

Es recomendable revisar nuevamente las cantidades antes de guardar los cambios.

---

## Recomendaciones

- Verificar siempre el cliente seleccionado.
- Confirmar cantidades antes de guardar.
- Evitar pedidos duplicados.
- Registrar observaciones cuando exista alguna instrucción especial para el repartidor.

---

## Relación entre módulos

El siguiente diagrama muestra cómo interactúan los módulos principales durante una venta.

```text
           CLIENTES
               │
               ▼
          PEDIDOS
               │
               ▼
            RUTA

    RUTAS DE REPARTIDORES
```

# 9. Créditos

El módulo **Créditos** permite administrar las ventas que no fueron liquidadas al momento de la entrega.

Su objetivo es mantener un control preciso de los saldos pendientes de cada cliente y registrar los pagos realizados.

---

## ¿Cuándo utilizar este módulo?

Utilice este módulo cuando:

- Un cliente compra a crédito.
- Se recibe un abono parcial.
- Se liquida completamente una deuda.
- Es necesario consultar el historial de pagos.

---

## Flujo del crédito

```text
           Venta
             │
             ▼
     Se genera el crédito
             │
             ▼
      Cliente realiza pago
             │
             ▼
      Registrar abono
             │
             ▼
 ¿Saldo pendiente?
      │            │
     Sí           No
      │            │
      ▼            ▼
 Continúa      Crédito liquidado
```

---

## Registrar un crédito

Normalmente el sistema genera el crédito automáticamente cuando una venta se realiza bajo esta modalidad.

Si el usuario cuenta con permisos suficientes podrá visualizar el nuevo registro dentro de la pestaña **Créditos**.

---

## Información disponible

Cada crédito puede mostrar:

- Cliente.
- Fecha.
- Monto original.
- Saldo pendiente.
- Estado.
- Historial de pagos.

---

## Registrar un abono

1. Abrir el módulo **Créditos**.

2. Buscar el cliente.

3. Seleccionar el crédito correspondiente.

4. Presionar:

**Registrar Abono**

5. Capturar el importe recibido.

6. Confirmar la operación.

El sistema actualizará automáticamente el saldo restante.

---

## Estados de un crédito

```text
Nuevo
 │
 ▼
Con Abonos
 │
 ▼
Liquidado
```

Cuando el saldo llega a cero, el crédito cambia automáticamente al estado **Liquidado**.

---

## Recomendaciones

- Verificar siempre el monto recibido antes de guardarlo.
- Registrar los pagos el mismo día en que se reciben.
- No modificar créditos antiguos sin autorización.
- Revisar el saldo pendiente antes de registrar un nuevo abono.

---

# 10. Ruta

La pestaña **Ruta** permite preparar la mercancía antes de salir a reparto.

Este módulo es utilizado principalmente por el administrador o personal autorizado.

Aquí se organiza la carga que llevará cada repartidor.

---

## Objetivo

Preparar correctamente la mercancía que será entregada durante la jornada.

Desde esta pantalla se asignan productos a una ruta específica antes de iniciar el recorrido.

---

## Flujo de preparación

```text
Pedidos
    │
    ▼
Preparación
    │
    ▼
Carga del vehículo
    │
    ▼
Asignación de ruta
    │
    ▼
Repartidor
```

---

## Crear una ruta

Seleccione la pestaña **Ruta**.

Posteriormente:

1. Elegir los pedidos correspondientes.
2. Seleccionar al repartidor.
3. Confirmar la carga.
4. Guardar la ruta.

Una vez finalizado este proceso, la información estará disponible para el repartidor.

---

## Información de la ruta

Cada ruta puede contener:

- Repartidor asignado.
- Fecha.
- Clientes incluidos.
- Productos cargados.
- Cantidades.
- Observaciones.

---

## Modificar una ruta

Mientras la ruta no haya iniciado, el administrador podrá:

- Agregar clientes.
- Eliminar clientes.
- Cambiar cantidades.
- Reasignar repartidor.

Una vez iniciada la entrega, algunas modificaciones podrán quedar restringidas.

---

## Recomendaciones

- Confirmar el inventario antes de guardar.
- Revisar que todos los pedidos estén incluidos.
- Verificar el repartidor asignado.
- Confirmar la fecha correcta de reparto.

---

## Indicadores sugeridos para el Dashboard

> **Nota:** Este gráfico es una recomendación para el manual y sirve para ilustrar los indicadores que el usuario puede interpretar durante la operación diaria.

### Interpretación

- **Pendientes:** pedidos aún no preparados.
- **En ruta:** pedidos asignados a un repartidor.
- **Entregados:** pedidos concluidos correctamente.
- **Cancelados:** pedidos anulados antes de la entrega.

Este tipo de indicador permite al administrador conocer rápidamente el estado general de la operación del día.
